# فيديو كلمات «بحبك يا أغلى الناس»

صفحة فيديو كلمات عربية بتصميم سينمائي متحرك، بنسبة 16:9، مع مشهد ليلي رومانسي وكلمات متزامنة.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادمًا محليًا من هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الصوت والتصدير

- من **اختيار ملف صوتي**، ارفع ملف الأغنية لمزامنة مدة الكلمات مع طول الملف.
- استخدم التشغيل أو شريط التوقيت لمعاينة الفيديو.
- اضغط **تصدير الفيديو** لتسجيل المشهد وتنزيله بصيغة WebM. إذا رُفع ملف صوتي، يُضمَّن صوته متى كان المتصفح يدعم التقاطه.
- يعمل التسجيل في المتصفحات الحديثة التي تدعم `MediaRecorder` و`canvas.captureStream` (مثل Chrome وEdge).

إذا لم يُرفع صوت، يعرض المشهد الكلمات على إيقاع تلقائي، من دون موسيقى.
